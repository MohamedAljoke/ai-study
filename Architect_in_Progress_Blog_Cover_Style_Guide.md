# Architect in Progress --- Blog Cover Style Guide

## Goal

Generate **consistent blog cover images** for the **Architect in
Progress** brand.

The result should look like a premium software engineering publication,
similar to the visual quality of Stripe, Vercel, Linear and GitHub
marketing.

------------------------------------------------------------------------

# Canvas

-   **Aspect ratio:** 16:9
-   **Resolution:** **1600 × 900 px**
-   Design for **Hashnode blog covers**.
-   Keep **all important content inside the central safe area**.
-   Leave **12--15% padding** on every edge.
-   Never place text or logos close to the borders.

------------------------------------------------------------------------

# Visual Style

-   Minimalist
-   Premium
-   Modern
-   Editorial
-   Developer focused
-   Flat/vector illustration
-   Subtle depth
-   High contrast
-   Lots of negative space

Avoid:

-   screenshots
-   IDE windows
-   terminal screenshots
-   code snippets
-   dashboards
-   forms
-   laptops
-   people
-   random decorative objects

------------------------------------------------------------------------

# Background

Use a subtle gradient only.

Colors:

-   #071529
-   #0B1D3A
-   #122440

Optional:

-   soft radial glow behind the technology logos
-   very subtle dotted pattern

The background must never compete with the title.

------------------------------------------------------------------------

# Brand

Top-left corner only.

Include:

-   Architect in Progress logo
-   "ARCHITECT IN PROGRESS"

Small and unobtrusive.

Never larger than **12% of the image width**.

------------------------------------------------------------------------

# Layout

Approximately:

┌────────────────────────────────────────────────────┐

Logo

BIG TITLE

                               Technology logos

└────────────────────────────────────────────────────┘

The left side occupies about **55%** of the width.

The right side occupies about **45%**.

------------------------------------------------------------------------

# Typography

Modern sans-serif.

Very bold.

Large.

Maximum **6--8 words**.

Maximum **3 lines**.

Highlight only technology names with accent colors.

Everything else stays white.

------------------------------------------------------------------------

# Accent Colors

Use **only one accent color per technology**.

Examples:

AWS → #FF9900

React → #61DAFB

TypeScript → #3178C6

Docker → #2496ED

Go → #00ADD8

Node.js → #5FA04E

Postgres → #336791

Kubernetes → #326CE5

Zod → #7C5CFC

Serverless → #FD5750

LocalStack → #6B6BFF

------------------------------------------------------------------------

# Technology Logos

Use only official logos.

Maximum three logos.

Large.

Clean.

No extra illustrations.

Stack them vertically when there are multiple technologies.

Examples:

AWS

↓

LocalStack

↓

Serverless

or

React + Zod

------------------------------------------------------------------------

# Composition Rules

-   Large title on the left.
-   Logos on the right.
-   Plenty of empty space.
-   Strong visual balance.
-   No clutter.
-   Nothing important near the borders.
-   Designed so Hashnode cropping never removes important content.
